Axiom Initiative multi-page website

Files:
- index.html: default entry point; redirects visitors to about.html
- about.html: About Us page (the landing page)
- mission.html: Mission page
- program.html: Programs page
- events.html: Events page
- gallery.html: Photo Gallery page
- contact.html: Get Involved / contact page
- styles.css: shared styles used by all pages
- images/: place your existing images here

Deployment:
1. Upload index.html, all .html pages, styles.css, and your images folder to the same GitHub Pages repository location.
2. Keep the image filenames and paths used by the HTML, including images/AxiomInitiative.png, images/about-math.jpg, and images/gallery-1.jpg through gallery-6.jpg.
3. GitHub Pages normally opens index.html automatically, which forwards visitors to about.html.
